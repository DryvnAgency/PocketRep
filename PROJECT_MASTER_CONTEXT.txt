1. PRODUCT OVERVIEW
================================================================================

PocketRep is a two-product suite for high-ticket sales reps:

  A) PocketRep (Mobile App) — Expo/React Native CRM for managing contacts,
     deals, sequences, and AI coaching via "Rex" voice assistant.

  B) Rex Lens (Chrome Extension) — Reads the rep's CRM, email, and LinkedIn
     in real-time and generates ready-to-send phone scripts, emails, and texts
     for every lead on screen.

Target users: Auto sales, mortgage, real estate, insurance, solar, B2B, HVAC,
staffing, roofing, fencing, door-to-door — any high-ticket relationship sale.

3. TECH STACK
================================================================================

Landing Page (Pocketrep/):
  - Static HTML/CSS/JS, deployed on Vercel
  - vercel.json handles rewrites and caching

Mobile App (PocketRepApp/):
  - Expo SDK / React Native (TypeScript)
  - Expo Router (file-based routing)
  - Supabase JS 2.39 (auth + database + edge functions)
  - Porcupine (voice wake word "Hey Rex")
  - expo-av (microphone/audio recording)
  - expo-location (proximity alerts)
  - expo-notifications (local push)
  - expo-secure-store (token storage)
  - EAS Build for iOS/Android distribution

Chrome Extension (RexLens/):
  - Manifest V3, TypeScript
  - esbuild (bundler): service-worker.js (ESM) + content-script.js (IIFE)
  - Shadow DOM panel injection (dark theme, resizable)
  - Supabase JS 2.49 (auth persistence via chrome.storage.local)
  - Platform adapters: VinSolutions, Gmail, Outlook, generic

Backend:
  - Supabase (PostgreSQL + Auth + Edge Functions + RLS)
  - Project: fwvrauqdoevwmwwqlfav.supabase.co
  - AI Proxy edge function (Gemini 2.5 Flash, translates Anthropic-format requests)
  - Support reply edge function (Twilio webhook auto-reply)

AI:
  - Gemini 2.5 Flash via Supabase edge function proxy
  - Model constants in RexLens/src/shared/prompts.ts
  - Usage tracked in daily_ai_usage table (per-user, per-day)

Payments:
  - Stripe Checkout (payment links, not embedded)
  - stripe_customer_id stored on profiles table

7. AI SYSTEM
================================================================================

Model: Gemini 2.5 Flash (via Supabase edge function proxy)
Proxy URL: https://fwvrauqdoevwmwwqlfav.supabase.co/functions/v1/ai-proxy/gemini
Auth: JWT from Supabase Auth (user must be logged in)

Request flow:
  Extension → callAIProxy() [Anthropic-format body]
    → Supabase Edge Function (ai-proxy)
      → Translates to Gemini format
      → Calls Google Gemini API (x-goog-api-key header)
      → Checks daily_ai_usage before calling
      → Logs tokens + cost after response
      → Returns Anthropic-shaped envelope to client

Prompt types:
  - PAGE_SCAN (Haiku-equivalent): quick page summary for background context
  - CHAT_MESSAGE (Sonnet-equivalent): full Rex coaching with page context
  - SCAN_BATCH: 30 tasks → personalized scripts (phone/email/text)
  - DEEP_REVIEW_SUMMARY: per-lead detail extraction
  - DEEP_REVIEW_GAME_PLAN: prioritized action plan for 30 leads

Pricing (Gemini 2.5 Flash):
  Input: $0.30/M tokens | Output: $2.50/M tokens
  ~$0.07 per 30-task scan batch | ~$0.01 per chat message
