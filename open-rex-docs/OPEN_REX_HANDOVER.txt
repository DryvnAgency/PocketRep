## DAY-ONE CHECKLIST

1. Clone
   git clone git@github.com:DryvnAgency/OpenRex.git
   cd OpenRex

2. Env
   cp .env.example .env.local
   Fill: SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE,
         GEMINI_API_KEY, TWILIO_* (messaging service SID + auth), APP_URL.

3. Schema
   Open Supabase SQL editor. Paste the idempotent migration block from
   OPEN_REX_MASTER_CONTEXT.txt section 4. Run once. Safe to re-run.

4. Run
   pnpm install
   pnpm dev                        # Next.js dashboard on :3000
   cd extension && pnpm build      # Rex Lens extension → dist/
   Load unpacked dist/ in chrome://extensions (developer mode).

5. Smoke test
   a. Open dashboard → sign in → should hit /health and return ok.
   b. Load extension on a VinSolutions worklist → "Scan My Page" → should
      return scripts for every visible task in <30s.
   c. "Deep Scan" one lead → should click through, parse profile, return
      game plan with 6-angle outreach choices.
   d. Mass outreach (SMS disabled until 10DLC) — email path should queue
      drafts to the review inbox.
