────────────────────────────────────────────────────────────────────────────────
WHY HIS PALABRA EXISTS
────────────────────────────────────────────────────────────────────────────────

His Palabra (Spanish for "His Word") exists because traditional Bible
translations — even "modern" ones like NIV or NLT — still read like textbooks
to Gen Z. Young people aged 16-30 consume language through TikTok, group chats,
tweets, and memes. They speak in a register built from slang markers like
"no cap", "fr fr", "deadass", "lowkey", "bussin", and "goated." No Bible app
speaks their language.

His Palabra solves this by presenting EVERY verse of the Bible in TWO forms:
  1. KJV (King James Version) — the classic, authoritative, public-domain text
  2. Gen Z Slang — the same verse re-voiced in heavy Urban Dictionary register

This is NOT a paraphrase. It's NOT "casual English." It's a full register swap
into the actual language Gen Z uses daily, while preserving every proper noun,
every theological concept, and every verse's meaning.

The entire 31,102-verse Bible has been translated into Gen Z slang and stored
in a Supabase PostgreSQL database. The app and translations are complete.

Example of the dual translation:
  KJV:   "The Lord is my shepherd; I shall not want."
  Slang: "The Lord got me fr — I'm never out here lacking, no cap."

  KJV:   "In the beginning God created the heaven and the earth."
  Slang: "Okay so straight up, in the beginning God created the heavens
          and the earth. That's it. That's how it started."

────────────────────────────────────────────────────────────────────────────────
SLANG TRANSLATION RULES (CRITICAL — APPLIES TO ALL CONTENT)
────────────────────────────────────────────────────────────────────────────────

DO:
  - Use Gen Z markers: "fr", "no cap", "deadass", "ngl", "lowkey", "bruh"
  - Use quality words: "bussin", "fire", "goated", "slay", "mid", "W/L"
  - Conversational tone (like a group chat or TikTok caption)
  - PRESERVE all proper nouns (Moses, David, Jerusalem, Jesus, Babylon)
  - PRESERVE all theological content (covenant, salvation, sin, grace)
  - CAPITALIZE "G" in God always ("on God" not "on god")

DON'T:
  - Use profanity (must be app-store safe)
  - Change the meaning of Scripture
  - Rename biblical figures
  - Delete theological concepts
  - Be disrespectful to the text

────────────────────────────────────────────────────────────────────────────────
SERVICES — lib/ and stores/
────────────────────────────────────────────────────────────────────────────────

lib/supabase.ts
  Creates and exports the Supabase client singleton.
  Platform-aware auth storage adapter:
    - Native (iOS/Android): uses expo-secure-store (encrypted keychain)
    - Web: uses localStorage
  Config: autoRefreshToken=true, persistSession=true, detectSessionInUrl=false.
  Imports react-native-url-polyfill for React Native compatibility.

stores/authStore.ts
  Zustand store managing all auth and profile state.

  State:
    session: Session | null — Supabase session
    user: User | null — Supabase auth user
    profile: Profile | null — App profile from profiles table
    loading: boolean — Initial load state
    initialized: boolean — Has initialize() completed?

  Actions:
    initialize() — Gets existing session, fetches profile, sets up
                    onAuthStateChange listener. Called once in _layout.tsx.
    signUp(email, password) — Creates account via Supabase Auth
    signIn(email, password) — Signs in via Supabase Auth
    signOut() — Signs out, clears all state
    fetchProfile() — SELECT * FROM profiles WHERE id = user.id
    updateProfile(updates) — UPDATE profiles SET ... WHERE id = user.id
                              Also updates local state optimistically.
