# PocketRep

**Work Your Book. Work Smarter.**

PocketRep is a Daily Sales Execution Engine for individual salespeople, starting with automotive sales reps. It turns an existing book of customers, leads, follow-ups, and missed opportunities into a prioritized daily work plan.

## Before making changes

Read these in order:

1. [`PROJECT_OPERATING_SYSTEM.md`](PROJECT_OPERATING_SYSTEM.md) — permanent product/engineering doctrine and decision framework.
2. [`CURRENT_STATE_DECISIONS.md`](CURRENT_STATE_DECISIONS.md) — living product state, locked business decisions, active work, and NOW/NEXT/LATER priorities.

Older handover/master-context files are historical references. When they conflict with the two files above, follow the truth-precedence rules in the Project Operating System and verify current production/code before acting.
