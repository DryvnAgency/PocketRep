📲 Install PocketRep

No app-store download is required to get started. PocketRep runs on the web and installs to your Home Screen.

🍎 iPhone / iPad

  1. Open pocketrep.pro in Safari.
  2. Tap Share.
  3. Tap Add to Home Screen.
  4. Tap Add.

🤖 Android

  1. Open pocketrep.pro in Chrome.
  2. Tap ⋮.
  3. Choose Install app or Add to Home screen.
  4. Confirm Install/Add.

💻 Computer

  1. Open pocketrep.pro in Chrome.
  2. Use the Install icon in the address bar.
  3. Or choose Install page as app from Chrome's menu.
  4. Open PocketRep from your app menu.
